# Codex Prompt — Soft Neo-Brutalism Portfolio Redesign

Redesign my existing developer portfolio website to closely match the visual design language of the provided reference screenshot.

Use the installed **Impeccable** skill to improve visual quality, consistency, and user experience. If the skill is unavailable, proceed using the design specifications below and report that limitation.

## 1. Design Style

Create a modern, playful, clean, and visually appealing developer portfolio using **Soft Neo-Brutalism + Playful Minimalism**.

The website should feel friendly, creative, polished, and professional. Avoid traditional corporate aesthetics, overly futuristic designs, excessive gradients, and generic AI-generated layouts.

## 2. Color Palette

| Element | Color | Hex |
|---|---|---|
| Background | Warm Cream | `#FAF8F1` |
| Primary | Soft Blue | `#4778E7` |
| Primary Hover | Darker Blue | `#3565D4` |
| Text / Border | Almost Black | `#171717` |
| Accent Red | Coral | `#F16B6B` |
| Accent Yellow | Pastel Yellow | `#FFD66B` |
| Card Background | White | `#FFFFFF` |

Use cream as the dominant background. Use blue selectively for buttons, highlights, headings, and decorations. These colors are approximate references, not exact values sampled from the original website.

## 3. Typography

- Headings: Plus Jakarta Sans or Outfit.
- Body: Inter or DM Sans.
- Large, bold hero heading.
- Strong visual hierarchy and comfortable line spacing.
- Consistent font weights and responsive sizes.
- Excellent readability.

## 4. Navigation Bar

Create a floating, pill-shaped navigation bar inspired by the reference screenshot:

- Cream or white background with a 2px solid black border.
- Fully rounded corners.
- Small circular logo on the left.
- Navigation links centered.
- Rounded menu button on the right.
- Subtle hover animations and responsive mobile navigation.

## 5. Hero Section

Create a two-column hero layout.

**Left side:**
- Small availability badge.
- Friendly greeting with a decorative icon.
- Large, bold name heading.
- Blue-highlighted developer role.
- Short personal introduction.
- Primary blue CTA and secondary outlined CTA.
- Small contact information.

**Right side:**
- Personal profile photograph (reuse existing assets; do not invent a personal photo).
- Rounded rectangular photo frame with bold black outline.
- Subtle offset shadow and blue circular background decoration.
- Small yellow star sticker and red sparkle.
- Location badge at the bottom of the photo, using existing accurate information only.

Follow the reference screenshot's composition as closely as practical while retaining the portfolio owner's identity and content.

## 6. Decorative Elements

Use small star stickers, sparkle icons, abstract circles, geometric shapes, and subtle hand-drawn accents. Keep decorations restrained and non-distracting.

## 7. About Me Section

Use a clean bento-grid-inspired layout featuring the existing personal introduction, background, interests, developer journey, and relevant highlights. Use rounded cards with subtle black borders.

## 8. Skills Section

Display technical skills in modern cards with consistent icon sizes, rounded corners, soft backgrounds, black outlines, subtle hover interactions, and a responsive grid.

## 9. Projects Section

Each project card should contain, where available:

- Project thumbnail.
- Project name and short description.
- Technology stack.
- GitHub link and live demo link.

Use rounded cards, black borders, subtle offset shadows, clean spacing, and smooth hover animations. Preserve all existing projects and correct links.

## 10. Contact Section

Create an inviting contact section with a large heading, short invitation, prominent contact button, social media links, and restrained playful decorations. Match the hero section's visual language.

## 11. Animations

Use purposeful motion: smooth hover transitions, button states, gentle card elevation, subtle entrance animations, and smooth scrolling. Avoid excessive movement and respect `prefers-reduced-motion`.

## 12. Responsive Design

Support desktop, laptop, tablet, and mobile. On mobile, stack hero content vertically, keep typography readable, adapt decorations, maintain spacing, prevent horizontal overflow, and ensure buttons remain accessible.

## 13. Important Constraints

- Preserve all existing content, functionality, routes, and projects.
- Do not modify backend logic.
- Reuse the current technology stack and styling conventions where practical.
- Avoid unnecessary dependencies.
- Maintain performance and accessibility.
- Do not fabricate personal information, credentials, work experience, or project details.
- Do not copy the reference person's name, photo, or biography.

## 14. Implementation Workflow

1. Analyze the existing project structure and identify the frontend framework and styling approach.
2. Audit the existing UI with Impeccable where available.
3. Define a consistent design system.
4. Redesign the navbar and hero section first; check their similarity to the reference.
5. Apply the design system to About, Skills, Projects, and Contact.
6. Add restrained animations and decorative elements.
7. Optimize responsive layouts and accessibility.
8. Run the production build and relevant checks, fixing any errors.
9. Summarize the changes and any remaining limitations.

## Reference Image

Use the user-provided screenshot as the **primary visual reference**. If it is stored in the project, look for `references/portfolio-design.png`. If it is missing, ask for its location rather than claiming to have inspected it.

## Final Goal

A polished, playful, premium developer portfolio with a warm cream background, soft blue accents, bold black outlines, rounded shapes, and charming sticker-style decorations—visually close to the reference while preserving the owner's original identity and functionality.
